# نظام إدارة الأصول الطبية — Medical Asset Management System

الإصدار 1.0 — واجهة أمامية كاملة (React + TypeScript + Vite) مع طبقة بيانات محلية (localStorage) قابلة للترقية إلى خادم لاحقًا.

Version 1.0 — a complete front-end (React + TypeScript + Vite) with a local data layer (localStorage) that can be upgraded to a real backend later.

> **بيانات تجريبية / Demo data:** جميع البيانات (الأصول، المستخدمون، الصيانة…) هي بيانات عرض توضيحي مُعلَّمة في المواصفات (القسم 28) وليست بيانات حقيقية.

## التشغيل / Run

```bash
npm install
npm run dev        # وضع التطوير / dev server
npm run build      # بناء الإنتاج / production build (tsc + vite)
npm run preview    # معاينة نسخة الإنتاج / preview the build
```

## أبرز الميزات / Key features

- واجهة ثنائية اللغة (عربي RTL / إنجليزي LTR) مع زر تبديل وحفظ التفضيل
- هوية بصرية "Modern Charcoal" (#292F38 / #477DA8) وخطوط IBM Plex Sans Arabic
- شريط جانبي قابل للطي (يُحفظ لكل مستخدم) مع شارة إشعارات
- لوحة معلومات: 8 مؤشرات، رسوم توزيع، طلبات حديثة، قائمة "يحتاج انتباه"، تقويم قادم، اتجاه الطلبات، سجل النشاط، فلاتر فترة
- الأصول: إضافة/تعديل/تفاصيل (5 أقسام نماذج)، 12 حالة، بحث وفلاتر متقدمة، استيراد CSV مع معاينة وتحقق، تصدير CSV وطباعة PDF، رمز QR لكل أصل
- الصيانة: 6 أنواع طلبات، 10 حالات، أوامر عمل، خطط صيانة وقائية مع توليد المهام ونسبة الالتزام
- المعايرة: سجلات بـ5 نتائج، مستحق قريبًا، شهادات منتهية، تذكيرات قابلة للضبط (90/30/7/0)
- التحويلات: طلبات متعددة الأصول بدورة اعتماد كاملة (إنشاء ← اعتماد ← تسليم ← استلام ← تحديث الموقع والحيازة تلقائيًا + سجل حركة)
- المواقع والأقسام، الموردون والعقود والضمانات، المستخدمون والأدوار (19 صلاحية + نطاق بيانات)، 16 تقريرًا، سجل تدقيق شامل، إعدادات
- RBAC مطبّق على الواجهة وعلى نطاق البيانات (الكل/القسم/الذات)

## حدود النسخة التجريبية / Demo limitations

- لا يوجد خادم خلفي: البيانات في `localStorage` (`mams.db.v1`) — جاهزة للاستبدال بـ API
- كلمات المرور مخزّنة كنص صريح للعرض التجريبي فقط (المواصفة تتطلب تشفيرًا عند ربط خادم حقيقي)
- تصدير Excel/PDF عبر CSV بترميز UTF-8 (يفتح في Excel) وزر الطباعة (حفظ كـ PDF)
- سجل التدقيق يسجّل IP تجريبيًا (`127.0.0.1`) لغياب الخادم
